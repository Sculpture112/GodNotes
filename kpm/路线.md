先解释几个文件名：

- `ELF`：一种可执行文件格式，全称是 Executable and Linkable Format。
- Android 的 `.so`、`linker64`、部分可执行文件，本质上都可能是 ELF 文件。
- `.ko`：Linux 内核模块，也就是可以加载到内核中的驱动模块。
- `.kpm`：KernelPatch 使用的模块格式，属于比较小众的专用领域。

## 一个通用搜索公式

以后遇到陌生文件或技术，可以用：

```

```

例如：

```
Android + so + 逆向
Linux + ko + 内核模块

```
