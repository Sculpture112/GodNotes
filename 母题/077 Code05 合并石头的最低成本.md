# [077 Code05 合并石头的最低成本]

> **原题链接:** (https://leetcode.cn/problems/minimum-cost-to-merge-stones/)

**题目简介:** 有一排石头，每次必须把连续的 `k` 堆合成一堆，代价是这 `k` 堆石头总数。求把所有石头合成一堆的最小总代价；如果做不到返回 `-1`。

**涉及知识点:** [[区间DP]], [[前缀和]]，[[待补题]],[[]],[[]]

**核心套路:** 先判断是否满足最终能合成一堆的必要条件 `(n - 1) % (k - 1) == 0`。再用区间 DP 计算每段“合并到不能再合并”为止的最小代价，并利用 `m += k - 1` 做关键剪枝。

## 破题切入点 (思维闪念)
[一段区间最后能剩几堆其实是固定的，所以分割点不是随便枚举，而是每次跳 `k - 1`，这样左右两段的目标堆数才能对上。]



```cpp
// 077 Code05 合并石头的最低成本

// 有n堆石头排成一排，第i堆中有stones[i]块石头
// 每次移动需要将连续的k堆石头合并为一堆，而这次移动的成本为这k堆中石头的总数
// 返回把所有石头合并成一堆的最低成本
// 如果无法合并成一堆返回-1
// 测试链接 : https://leetcode.cn/problems/minimum-cost-to-merge-stones/

#include <iostream>
#include <vector>
#include <algorithm>
#include <climits>

using namespace std;

class Code05_MinimumCostToMergeStones {
public:
    // 时间复杂度O(n^3)
    static int mergeStones(vector<int>& stones, int k) {
        int n = stones.size();
        if ((n - 1) % (k - 1) != 0) {
            return -1;
        }
        vector<int> presum(n + 1, 0);
        for (int i = 0; i < n; i++) {
            presum[i + 1] = presum[i] + stones[i];
        }
        vector<vector<int>> dp(n, vector<int>(n, 0));
        for (int l = n - 2; l >= 0; l--) {
            for (int r = l + 1; r < n; r++) {
                int ans = INT_MAX;
                for (int m = l; m < r; m += k - 1) {
                    ans = min(ans, dp[l][m] + dp[m + 1][r]);
                }
                if ((r - l) % (k - 1) == 0) {
                    ans += presum[r + 1] - presum[l];
                }
                dp[l][r] = ans;
            }
        }
        return dp[0][n - 1];
    }
};
```
