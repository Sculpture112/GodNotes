# [078 Code05 没有上司的舞会]

> **原题链接:** (https://www.luogu.com.cn/problem/P1352)
> **相似题链接:** (https://leetcode.cn/problems/house-robber-iii/)

**题目简介:** 给定一棵上下级关系树，每个员工有快乐值。若某员工参加，则其直接下属不能参加。求邀请方案的最大总快乐值。

**涉及知识点:** [[树形DP]], [[链式前向星]]，[[待补题]],[[]],[[]]

**核心套路:** 树上打家劫舍。定义 `yes[u]` 表示 `u` 来时整棵子树最大快乐值，`no[u]` 表示 `u` 不来时整棵子树最大快乐值，后序转移即可。

## 破题切入点 (思维闪念)
[父子不能同时选，这是最典型的树形 DP 二选一模型：当前节点来不来，各自把对子树的限制写清楚。]



```cpp
// 078 Code05 没有上司的舞会

// 某大学有n个职员，编号为1...n
// 他们之间有从属关系，也就是说他们的关系就像一棵以校长为根的树
// 父结点就是子结点的直接上司
// 现在有个周年庆宴会，宴会每邀请来一个职员都会增加一定的快乐指数
// 但是如果某个职员的直接上司来参加舞会了，那么这个职员就无论如何也不肯来参加舞会了
// 所以请你编程计算邀请哪些职员可以使快乐指数最大，返回最大的快乐指数
// 测试链接 : https://www.luogu.com.cn/problem/P1352
// 链接题 : https://leetcode.cn/problems/house-robber-iii/

#include <iostream>
#include <algorithm>
#include <cstring>

using namespace std;

class Code05_Dancing {
public:
    static const int MAXN = 6001;

    static int nums[MAXN];
    static bool boss[MAXN];
    static int head[MAXN];
    static int nxt[MAXN];
    static int to[MAXN];
    static int cnt;
    static int no[MAXN];
    static int yes[MAXN];
    static int n, h;

    static void build(int n) {
        for (int i = 1; i <= n; i++) {
            boss[i] = true;
            head[i] = 0;
        }
        cnt = 1;
    }

    static void addEdge(int u, int v) {
        nxt[cnt] = head[u];
        to[cnt] = v;
        head[u] = cnt++;
    }

    static void f(int u) {
        no[u] = 0;
        yes[u] = nums[u];
        for (int ei = head[u]; ei > 0; ei = nxt[ei]) {
            int v = to[ei];
            f(v);
            no[u] += max(no[v], yes[v]);
            yes[u] += no[v];
        }
    }
};

int Code05_Dancing::nums[Code05_Dancing::MAXN];
bool Code05_Dancing::boss[Code05_Dancing::MAXN];
int Code05_Dancing::head[Code05_Dancing::MAXN];
int Code05_Dancing::nxt[Code05_Dancing::MAXN];
int Code05_Dancing::to[Code05_Dancing::MAXN];
int Code05_Dancing::cnt;
int Code05_Dancing::no[Code05_Dancing::MAXN];
int Code05_Dancing::yes[Code05_Dancing::MAXN];
int Code05_Dancing::n;
int Code05_Dancing::h;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    while (cin >> Code05_Dancing::n) {
        Code05_Dancing::build(Code05_Dancing::n);
        for (int i = 1; i <= Code05_Dancing::n; i++) {
            cin >> Code05_Dancing::nums[i];
        }
        for (int i = 1; i < Code05_Dancing::n; i++) {
            int low, high;
            cin >> low >> high;
            Code05_Dancing::addEdge(high, low);
            Code05_Dancing::boss[low] = false;
        }
        for (int i = 1; i <= Code05_Dancing::n; i++) {
            if (Code05_Dancing::boss[i]) {
                Code05_Dancing::h = i;
                break;
            }
        }
        Code05_Dancing::f(Code05_Dancing::h);
        cout << max(Code05_Dancing::no[Code05_Dancing::h], Code05_Dancing::yes[Code05_Dancing::h]) << '\n';
    }
    return 0;
}
```
