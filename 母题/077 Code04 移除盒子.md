# [077 Code04 移除盒子]

> **原题链接:** (https://leetcode.cn/problems/remove-boxes/)

**题目简介:** 有一排不同颜色的盒子，每次可以删除一段连续且颜色相同的盒子，若这一段长度为 `k` 就能得到 `k * k` 分。求全部删完的最大总分。

**涉及知识点:** [[区间DP]], [[记忆化搜索]]，[[待补题]],[[已AC]],[[]]

**核心套路:** 经典三维记忆化搜索。`f(l, r, k)` 表示处理 `l...r` 这段时，左边还额外跟着 `k` 个与 `boxes[l]` 同色盒子时的最大得分。

## 破题切入点 (思维闪念)
[当前开头这段同色盒子，可以选择“现在就消掉”，也可以尝试和后面某个同色位置拼在一起再消。]



```cpp
// 077 Code04 移除盒子

// 给出一些不同颜色的盒子boxes，盒子的颜色由不同的正数表示
// 你将经过若干轮操作去去掉盒子，直到所有的盒子都去掉为止
// 每一轮你可以移除具有相同颜色的连续k个盒子(k >= 1)
// 这样一轮之后你将得到k * k个积分
// 返回你能获得的最大积分总和
// 测试链接 : https://leetcode.cn/problems/remove-boxes/

#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

class Code04_RemoveBoxes {
public:
    // 时间复杂度O(n^4)
    static int removeBoxes(vector<int>& boxes) {
        int n = boxes.size();
        if (n == 0) {
            return 0;
        }
        vector<vector<vector<int>>> dp(n, vector<vector<int>>(n, vector<int>(n, 0)));
        return f(boxes, 0, n - 1, 0, dp);
    }

    // boxes[l...r]范围上要去消除，前面跟着k个连续的和boxes[l]颜色一样的盒子
    // 这种情况下，返回最大得分
    static int f(const vector<int>& boxes, int l, int r, int k, vector<vector<vector<int>>>& dp) {
        if (l > r) {
            return 0;
        }
        if (dp[l][r][k] > 0) {
            return dp[l][r][k];
        }
        int s = l;
        while (s + 1 <= r && boxes[l] == boxes[s + 1]) {
            s++;
        }
        int cnt = k + s - l + 1;
        int ans = cnt * cnt + f(boxes, s + 1, r, 0, dp);
        for (int m = s + 2; m <= r; m++) {
            if (boxes[l] == boxes[m] && boxes[m - 1] != boxes[m]) {
                ans = max(ans, f(boxes, s + 1, m - 1, 0, dp) + f(boxes, m, r, cnt, dp));
            }
        }
        dp[l][r][k] = ans;
        return ans;
    }
};
```
