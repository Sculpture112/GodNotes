# [077 Code01 完成配对需要的最少字符数量]0

> **原题链接:** (https://www.nowcoder.com/practice/e391767d80d942d29e6095a935a5b96b)

**题目简介:** 给定一个只由 `[`、`]`、`(`、`)` 组成的字符串，求最少还要插入多少个括号，才能让整个字符串完全正确配对。

**涉及知识点:** [[区间DP]], [[记忆化搜索]]，[[待补题]],[[]],[[]]

**核心套路:** 设 `dp[l][r]` 表示让区间 `l...r` 完全匹配所需的最少插入次数，转移时讨论“两端直接配对”以及“在某个位置切开分成两段”这两类情况。

## 破题切入点 (思维闪念)
[把“最少补几个字符”定义成区间代价，然后枚举当前区间是两端配对更优，还是从中间切开更优。]



```cpp
// 077 Code01 完成配对需要的最少字符数量

// 给定一个由'['、']'、'('、')'组成的字符串
// 请问最少插入多少个括号就能使这个字符串的所有括号正确配对
// 例如当前串是 "([[])"，那么插入一个']'即可满足
// 输出最少需要插入多少个字符
// 测试链接 : https://www.nowcoder.com/practice/e391767d80d942d29e6095a935a5b96b

#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <climits>

using namespace std;

class Code01_MinimumInsertionsToMatch {
public:
    // 时间复杂度O(n^3)
    static int compute(const string& str) {
        if (str.empty()) {
            return 0;
        }
        vector<char> s(str.begin(), str.end());
        int n = s.size();
        vector<vector<int>> dp(n, vector<int>(n, -1));
        return f(s, 0, n - 1, dp);
    }

    // 让s[l...r]配对至少需要几个字符
    static int f(const vector<char>& s, int l, int r, vector<vector<int>>& dp) {
        if (l == r) {
            return 1;
        }
        if (l == r - 1) {
            if ((s[l] == '(' && s[r] == ')') || (s[l] == '[' && s[r] == ']')) {
                return 0;
            }
            return 2;
        }
        if (dp[l][r] != -1) {
            return dp[l][r];
        }
        int p1 = INT_MAX;
        if ((s[l] == '(' && s[r] == ')') || (s[l] == '[' && s[r] == ']')) {
            p1 = f(s, l + 1, r - 1, dp);
        }
        int p2 = INT_MAX;
        for (int m = l; m < r; m++) {
            p2 = min(p2, f(s, l, m, dp) + f(s, m + 1, r, dp));
        }
        int ans = min(p1, p2);
        dp[l][r] = ans;
        return ans;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string str;
    if (getline(cin, str)) {
        cout << Code01_MinimumInsertionsToMatch::compute(str) << '\n';
    }
    return 0;
}
```
