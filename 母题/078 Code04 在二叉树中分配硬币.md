# [078 Code04 在二叉树中分配硬币]

> **原题链接:** (https://leetcode.cn/problems/distribute-coins-in-binary-tree/)

**题目简介:** 一棵有 `n` 个节点的二叉树上总共有 `n` 枚硬币，每次可以在相邻节点间移动一枚硬币。求让每个节点最终恰好有一枚硬币所需的最少移动次数。

**涉及知识点:** [[树形DP]], [[后序遍历]]，[[待补题]],[[]],[[]]

**核心套路:** 每棵子树向上返回三个量：节点数、硬币总数、子树内部最少移动次数。左右子树各自多余或缺少的硬币量，就是必须跨边传递的次数。

## 破题切入点 (思维闪念)
[对子树来说，只要知道“这棵子树有几个节点、几枚硬币”，就能知道它最终要向父亲要多少或给多少。]



```cpp
// 078 Code04 在二叉树中分配硬币

// 给你一个有n个结点的二叉树的根结点root
// 其中树中每个结点node都对应有node.val枚硬币
// 整棵树上一共有n枚硬币
// 在一次移动中，我们可以选择两个相邻的结点，然后将一枚硬币从其中一个结点移动到另一个结点
// 返回使每个结点上只有一枚硬币所需的最少移动次数
// 测试链接 : https://leetcode.cn/problems/distribute-coins-in-binary-tree/

#include <cmath>

using namespace std;

class Code04_DistributeCoins {
public:
    struct TreeNode {
        int val;
        TreeNode* left;
        TreeNode* right;
        TreeNode() : val(0), left(nullptr), right(nullptr) {}
        TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
        TreeNode(int x, TreeNode* l, TreeNode* r) : val(x), left(l), right(r) {}
    };

    struct Info {
        int cnt;
        int sum;
        int move;

        Info(int a, int b, int c) : cnt(a), sum(b), move(c) {}
    };

    static int distributeCoins(TreeNode* root) {
        return f(root).move;
    }

    static Info f(TreeNode* x) {
        if (x == nullptr) {
            return Info(0, 0, 0);
        }
        Info infol = f(x->left);
        Info infor = f(x->right);
        int cnts = infol.cnt + infor.cnt + 1;
        int sums = infol.sum + infor.sum + x->val;
        int moves = infol.move + infor.move + abs(infol.cnt - infol.sum) + abs(infor.cnt - infor.sum);
        return Info(cnts, sums, moves);
    }
};
```
