# [077 Code02 涂色 & 奇怪打印机]

> **原题链接:** (https://www.luogu.com.cn/problem/P4170)
> **同题链接:** (https://leetcode.cn/problems/strange-printer/)


很简单

**题目简介:** 一开始木板没有颜色，每次可以把一段连续区间刷成同一种颜色，后刷会覆盖前刷。给定目标颜色串，求最少需要刷多少次。

**涉及知识点:** [[区间DP]], [[分类讨论]]，[[待补题]],[[]],[[]]

**核心套路:** 设 `dp[l][r]` 表示刷出子串 `l...r` 的最少次数。如果两端字符相同，可以让右端借用左边最后一次涂色；否则枚举分割点做区间划分。

## 破题切入点 (思维闪念)
[先想最后一次涂色怎么影响两端字符，相同字符可以合并一次操作，不同字符就只能拆区间。]

// 077 Code02 涂色 & 奇怪打印机

// 假设你有一条长度为5的木板，初始时没有涂过任何颜色
// 你希望把它的5个单位长度分别涂上红、绿、蓝、绿、红
// 用一个长度为5的字符串表示这个目标 : RGBGR
// 每次你可以把一段连续的木板涂成一个给定的颜色，后涂的颜色覆盖先涂的颜色
// 返回尽量少的涂色次数
// 测试链接 : https://www.luogu.com.cn/problem/P4170
// 测试链接 : https://leetcode.cn/problems/strange-printer/

#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <climits>

using namespace std;

class Code02_Coloring {
public:
    // 时间复杂度O(n^3)
    static int strangePrinter(const string& str) {
        if (str.empty()) {
            return 0;
        }
        vector<char> s(str.begin(), str.end());
        int n = s.size();
        vector<vector<int>> dp(n, vector<int>(n, 0));
        dp[n - 1][n - 1] = 1;
        for (int i = 0; i < n - 1; i++) {
            dp[i][i] = 1;
            dp[i][i + 1] = s[i] == s[i + 1] ? 1 : 2;
        }
        for (int l = n - 3; l >= 0; l--) {
            for (int r = l + 2; r < n; r++) {
                if (s[l] == s[r]) {
                    dp[l][r] = dp[l][r - 1];
                } else {
                    int ans = INT_MAX;
                    for (int m = l; m < r; m++) {
                        ans = min(ans, dp[l][m] + dp[m + 1][r]);
                    }
                    dp[l][r] = ans;
                }
            }
        }
        return dp[0][n - 1];
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string str;
    if (getline(cin, str)) {
        cout << Code02_Coloring::strangePrinter(str) << '\n';
    }
    return 0;
}
