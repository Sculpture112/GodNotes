# [078 Code06 监控二叉树]

> **原题链接:** (https://leetcode.cn/problems/binary-tree-cameras/)

**题目简介:** 在二叉树的一些节点上安装摄像头，每个摄像头能监控父节点、自己和直接孩子。求覆盖整棵树所需的最少摄像头数量。

**涉及知识点:** [[树形DP]], [[贪心算法]]，[[待补题]],[[]],[[]]

**核心套路:** 用递归返回三种状态：未覆盖、已覆盖但无相机、已覆盖且有相机。若孩子有未覆盖节点，当前节点必须放相机；若孩子都已覆盖无相机，当前节点暂时设为未覆盖。

## 破题切入点 (思维闪念)
[把节点状态压成 3 类后，决策会非常直接：孩子缺监控，就在当前补；孩子都安全，当前就尽量别装。]



```cpp
// 078 Code06 监控二叉树

// 给定一个二叉树，我们在树的节点上安装摄像头
// 节点上的每个摄影头都可以监视其父对象、自身及其直接子对象
// 计算监控树的所有节点所需的最小摄像头数量
// 测试链接 : https://leetcode.cn/problems/binary-tree-cameras/

using namespace std;

class Code06_BinaryTreeCameras {
public:
    struct TreeNode {
        int val;
        TreeNode* left;
        TreeNode* right;
        TreeNode() : val(0), left(nullptr), right(nullptr) {}
        TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
        TreeNode(int x, TreeNode* l, TreeNode* r) : val(x), left(l), right(r) {}
    };

    int ans = 0;

    int minCameraCover(TreeNode* root) {
        ans = 0;
        if (f(root) == 0) {
            ans++;
        }
        return ans;
    }

    // 0 : 当前节点未覆盖，但子树下方都已覆盖
    // 1 : 当前节点已覆盖，当前节点无相机
    // 2 : 当前节点已覆盖，当前节点有相机
    int f(TreeNode* x) {
        if (x == nullptr) {
            return 1;
        }
        int left = f(x->left);
        int right = f(x->right);
        if (left == 0 || right == 0) {
            ans++;
            return 2;
        }
        if (left == 1 && right == 1) {
            return 0;
        }
        return 1;
    }
};
```
