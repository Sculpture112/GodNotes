```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;

    while (t--) {
        int n;
        cin >> n;

        vector<ll> a(n), diff(n - 1);
        for (ll &x : a) cin >> x;

        for (int i = 0; i + 1 < n; ++i) {
            diff[i] = a[i + 1] - a[i];
        }

        int left = 0;
        while (left < n - 1) {
            int right = left + 1;

            while (right < n - 1 &&
                   (diff[right] % 2 != 0) == (diff[left] % 2 != 0)) {
                ++right;
            }

            sort(diff.begin() + left, diff.begin() + right);
            left = right;
        }

        ll current = a[0];
        cout << current;

        for (ll d : diff) {
            current += d;
            cout << ' ' << current;
        }
        cout << '\n';
    }

    return 0;
}
```

D. 数组替换

每个测试点时间限制：2 秒  
每个测试点内存限制：256 MB

给定一个长度为 `n` 的数组 `a`。

你可以进行任意次操作（也可以一次都不进行）：

- 选择一个下标 `i`（`2 ≤ i ≤ n - 1`），使得 `a[i - 1]` 和 `a[i + 1]` 的奇偶性相同。 
- 将 `a[i]` 替换为 `a[i - 1] - a[i] + a[i + 1]`。
// 这里替换之后,要自行觉察出规律,发现,一次操作之后,会使差分数组交换.
// 具体来说就是,对i操作,等价于 `d[i] 与 d[i+1]交换  d[i] = a[i+1] - a[i]  ,  d[i +1] = a[i+2] - a[i+1];`  
// 这里可以用前后变化的量进行观察,也可以带入实例观察
// 最后 再通过a1 + d1 = a2 ,可以构造出后续的数字,即可通过交换区域内(奇偶性一致)的差分数组,来使字典序下降(排序);


求经过任意次操作后，能够得到的字典序最小的数组。

对于两个长度相同的序列 `x` 和 `y`，如果在第一个满足 `x[i] ≠ y[i]` 的位置上，`x[i] < y[i]`，那么称序列 `x` 的字典序小于序列 `y`。

**输入**

每个输入包含多组测试数据。第一行包含测试用例数量 `t`（`1 ≤ t ≤ 10^4`）。

每组测试数据的第一行包含一个整数 `n`（`3 ≤ n ≤ 2 × 10^5`），表示数组 `a` 的长度。

第二行包含 `n` 个整数 `a1, a2, ..., an`（`-10^9 ≤ ai ≤ 10^9`）。

保证所有测试用例的 `n` 之和不超过 `2 × 10^5`。

**输出**

对于每个测试用例，输出 `n` 个整数，表示可以得到的字典序最小数组。

**样例说明**

第二组测试中，初始数组为 `[1, 2, 3]`。唯一可选的下标是 `i = 2`，因为 `a1 = 1` 和 `a3 = 3` 都是奇数。替换后：

```
a2 = 1 - 2 + 3 = 2
```

数组没有改变，因此最小数组为 `[1, 2, 3]`。

第三组测试中，初始数组为 `[10, 10, 8, 4]`。可以依次进行以下操作：

- 选择 `i = 2`，将 `a2` 替换为 `10 - 10 + 8 = 8`，数组变为 `[10, 8, 8, 4]`。
- 选择 `i = 3`，将 `a3` 替换为 `8 - 8 + 4 = 4`，数组变为 `[10, 8, 4, 4]`。
- 选择 `i = 2`，将 `a2` 替换为 `10 - 8 + 4 = 6`，数组变为 `[10, 6, 4, 4]`。

可以证明，`[10, 6, 4, 4]` 是所有可得到数组中字典序最小的。
