# 公约数与公倍数：概念、C++ 函数与洛谷例题

## 先说明：函数是不是现成的？需要什么头文件？

**它们是“内置函数”吗？** 如果你想问“C++ 有没有已经写好的函数，可以直接调用”，答案是有：`std::gcd` 和 `std::lcm` 都已经由标准库提供，不需要自己实现。严格来说，它们叫作**标准库函数**，并非语言语法本身内置的运算。

 它们对应的头文件是 **`<numeric>`**，需要 **C++17 或更新版本**。`<iostream>` 主要提供输入输出功能，例如 `std::cin` 和 `std::cout`。

| 头文件 | 本讲义中用到的功能 |
| --- | --- |
| `<iostream>` | `std::cin` 读入、`std::cout` 输出 |
| `<numeric>` | `std::gcd` 最大公约数、`std::lcm` 最小公倍数 |

因此，程序既要输入输出，又要调用 gcd/lcm，就应当同时包含这两个头文件。不要依赖某个编译环境偶然间接包含了其他头文件。

```cpp
#include <iostream>  // std::cin、std::cout
#include <numeric>   // std::gcd、std::lcm（C++17 起）
```

**`std::` 可以省略吗？** `std` 是标准库使用的命名空间。没有写 `using namespace std;` 时，调用应写完整名称 `std::gcd`、`std::lcm`。

如果在头文件后面写了 `using namespace std;`，就可以直接写 `gcd(a, b)`、`lcm(a, b)`，以及 `cin`、`cout`。这只是名称写法的区别，仍然需要包含对应的头文件。

> **阅读路线**：公约数与最大公约数 → 公倍数与最小公倍数 → C++ 函数用法 → 求法原理 → 洛谷例题。
>
> **代码环境**：C++17。数学概念先讨论正整数；涉及 0、负数时单独说明。
>

## 1. 公约数与最大公约数

### 1.1 什么是约数？

如果一个正整数能够把另一个正整数整除，它就是后者的一个**约数**，也叫**因数**。

例如，`12 ÷ 3 = 4`，没有余数，所以 3 是 12 的约数；而 `12 ÷ 5` 有余数，所以 5 不是 12 的约数。

在 C++ 中，`%` 表示取余。判断 `d` 是不是 `a` 的约数，可以写：

```cpp
// 前提：a、d 是正整数。
if (a % d == 0) {
    // d 是 a 的约数。
}
```

### 1.2 什么是公约数？

**两个数共同拥有的约数，就是它们的公约数。**

以 12 和 18 为例：

| 对象 | 全部正约数 |
| --- | --- |
| 12 | 1、2、3、4、6、12 |
| 18 | 1、2、3、6、9、18 |
| 共同拥有 | 1、2、3、6 |

所以，12 和 18 的公约数是 **1、2、3、6**。

判断 `d` 是不是 `a`、`b` 的公约数：

```cpp
if (a % d == 0 && b % d == 0) {
    // d 同时整除 a 和 b。
}
```

### 1.3 什么是最大公约数？

所有公约数中，**最大的那个**叫作最大公约数，英文缩写为 **gcd**。

$$
\gcd(12,18)=6
$$

这里容易混淆的是：**“公约数”可能有多个，“最大公约数”只有一个。** `gcd` 函数只返回最大的那个，不会返回所有公约数。

生活中的理解：把 12 个苹果和 18 个橘子分成若干份，每份的苹果数量相同、橘子数量也相同，而且没有剩余。能分的份数是 1、2、3、6，最多分 6 份。

### 1.4 什么是互质？

如果两个正整数的最大公约数是 1，就说它们**互质**。

例如，8 和 15 互质。互质不要求两个数本身都是质数。

```cpp
if (std::gcd(a, b) == 1) {
    // a 与 b 互质。
}
```

## 2. 公倍数与最小公倍数

### 2.1 什么是倍数？

把一个正整数乘以 1、2、3……，得到的就是它的正倍数。

例如，12 的正倍数有 12、24、36、48、60……

如果 `m % a == 0`，可以说 **a 是 m 的约数**，也可以说 **m 是 a 的倍数**。两句话描述的是同一个整除关系，方向不同。

### 2.2 什么是公倍数？

**同时是两个数倍数的数，就是它们的公倍数。** 本讲义基础部分只讨论正公倍数。

以 12 和 18 为例：

| 对象 | 一部分正倍数 |
| --- | --- |
| 12 | 12、24、36、48、60、72、84、96、108…… |
| 18 | 18、36、54、72、90、108…… |
| 共同拥有 | 36、72、108…… |

所以，36、72、108……都是 12 和 18 的公倍数。

```cpp
if (m % a == 0 && m % b == 0) {
    // m 同时是 a、b 的倍数。
}
```

### 2.3 什么是最小公倍数？

所有**正公倍数**中，最小的那个叫作最小公倍数，英文缩写为 **lcm**。

$$
\operatorname{lcm}(12,18)=36
$$

必须强调“正”：0 能被任何非零整数整除，但这里不能把 0 当成两个正整数的最小公倍数。

生活中的理解：两盏灯在同一时刻闪了一次，之后一盏每隔 12 秒闪一次，另一盏每隔 18 秒闪一次。它们第一次再次同时闪，是 36 秒后。

### 2.4 两个概念放在一起比较

| 比较项 | 最大公约数 gcd | 最小公倍数 lcm |
| --- | --- | --- |
| 这个数与原数的关系 | 它能整除两个原数 | 两个原数都能整除它 |
| 从哪些数里选 | 全部正公约数 | 全部正公倍数 |
| 选哪个 | 最大的 | 最小的 |
| 12 和 18 的答案 | 6 | 36 |
| 常见用途 | 约分、等份分组、互质判断 | 周期重合、统一分母 |

对于正整数，有：

$$
\gcd(a,b)\leq \min(a,b),\qquad
\operatorname{lcm}(a,b)\geq \max(a,b)
$$

## 3. C++ 标准函数怎么用？

### 3.1 头文件与版本

从 **C++17** 开始，标准库在 `<numeric>` 中提供 `std::gcd` 和 `std::lcm`。在洛谷提交下面的代码时，选择支持 C++17 或更新标准的编译选项。

```cpp
#include <iostream>  // std::cin、std::cout
#include <numeric>   // std::gcd、std::lcm（C++17 起）

int main() {
    long long a, b;
    std::cin >> a >> b;

    long long g = std::gcd(a, b);
    long long l = std::lcm(a, b);

    std::cout << g << ' ' << l << '\n';
    return 0;
}
```

输入：

```text
12 18
```

输出：

```text
6 36
```

这段程序适用于输入的绝对值和最小公倍数都能用 `long long` 表示的情况。

### 3.2 参数和返回值

| 写法 | 参数含义 | 返回值 |
| --- | --- | --- |
| `std::gcd(a, b)` | 要求最大公约数的两个整数 | 两数绝对值的最大公约数 |
| `std::lcm(a, b)` | 要求最小公倍数的两个整数 | 两数绝对值的最小公倍数；有参数为 0 时返回 0 |

```cpp
long long a = 12, b = 18;

long long g = std::gcd(a, b);  // g = 6
long long l = std::lcm(a, b);  // l = 36
```

逐行理解：

1. 把 `a`、`b` 的值交给函数。
2. 函数计算结果并返回。
3. 用变量 `g`、`l` 接住返回值。

**调用函数不会改变 `a` 和 `b`。** 调用后，它们仍然是 12 和 18。

这两个函数用于整数类型，不能传入 `double` 这样的浮点数，也不能传入 `bool`。

### 3.3 0 和负数怎么处理？

标准库的行为如下：

```cpp
std::gcd(0, 18);    // 18
std::gcd(12, 0);    // 12
std::gcd(0, 0);     // 0
std::gcd(-12, 18);  // 6

std::lcm(0, 18);    // 0
std::lcm(0, 0);     // 0
std::lcm(-12, 18);  // 36
```

这里的 `gcd(0,0)=0` 和含 0 时 `lcm=0` 是标准库约定，与前面“两个正整数”的讨论范围不同。

### 3.4 为什么建议把参数定义成 long long？

最小公倍数可能远大于两个输入。

例如，100000 和 99999 互质，最小公倍数是 9999900000，超出了常见 32 位 `int` 的范围。

注意：**函数根据参数类型计算，不会因为外面的接收变量是 `long long` 就自动使用更宽的类型。**

```cpp
int a = 100000, b = 99999;

// 错误用法：两个参数都是 int，结果超出 int 的表示范围。
// long long ans = std::lcm(a, b);

// 正确：调用前，就把参数转换成 long long。
long long ans = std::lcm(1LL * a, 1LL * b);
```

如果输入本身已经是 `long long`，直接调用即可。

`long long` 也有范围上限。标准函数不会替你处理超出结果类型范围的答案；另外，参数的绝对值也必须能用两参数的公共类型表示，例如不要直接调用 `std::gcd(LLONG_MIN, 0LL)`。

## 4. 函数背后的求法

### 4.1 最大公约数：辗转相除法

先看 48 和 18：

```text
48 ÷ 18 = 2，余 12
18 ÷ 12 = 1，余 6
12 ÷  6 = 2，余 0
```

对应的状态变化：

```text
(48, 18) → (18, 12) → (12, 6) → (6, 0)
```

当第二个数变成 0 时，第一个数 6 就是答案。

核心关系是：

$$
\gcd(a,b)=\gcd(b,a\bmod b)\qquad (b>0)
$$

其中 `a % b` 就是上面的余数。

**为什么替换后答案不变？**

设商为 $q$，余数为 $r$，那么：

$$
a=bq+r,\qquad r=a-bq
$$

- 如果 $d$ 同时整除 $a$ 和 $b$，它也能整除 $a-bq$，也就是 $r$。
- 反过来，如果 $d$ 同时整除 $b$ 和 $r$，它也能整除 $bq+r$，也就是 $a$。

所以，`a、b` 的公约数和 `b、r` 的公约数完全相同，最大公约数也就相同。

每次非零余数都小于除数，因此这个过程一定会结束。当 `b == 0` 时，`a` 与 0 的最大公约数就是 `a`，因为每个正整数都能整除 0。

### 4.2 手写 gcd

下面的模板约定参数是**非负整数**，不额外处理负数。

```cpp
long long gcd_ll(long long a, long long b) {
    while (b != 0) {
        long long r = a % b;
        a = b;
        b = r;
    }
    return a;
}
```

代码流程：

1. `r = a % b`：先保存旧的两个数相除的余数。
2. `a = b`：把旧的除数变成新的被除数。
3. `b = r`：把余数变成新的除数。
4. 重复，直到 `b == 0`，返回 `a`。

不能在保存余数之前就覆盖 `a`，否则计算余数时用到的将不再是原来的 `a`。

对正整数，辗转相除法的时间复杂度为 $O(\log \min(a,b))$，循环版本的额外空间复杂度为 $O(1)$。列举所有可能的公约数也能求解，但大数情况下逐个试除远慢于辗转相除法；列举法适合帮助理解概念。

### 4.3 最小公倍数：先求 gcd，再计算

对两个正整数，有：

$$
\gcd(a,b)\times\operatorname{lcm}(a,b)=a\times b
$$

于是：

$$
\operatorname{lcm}(a,b)=\frac{a}{\gcd(a,b)}\times b
$$

用 12 和 18 检查：`12 / 6 * 18 = 36`。

**为什么这个关系成立？** 把两个数分解成质因数：

$$
12=2^2\times3^1,\qquad18=2^1\times3^2
$$

- 公约数必须能整除两数，所以每个质因子的指数不能超过两边较小的指数；取到最大时，gcd 对每个质因子取**较小指数**。
- 公倍数必须包含两数所需的全部质因子，所以每个质因子的指数不能低于两边较大的指数；取到最小时，lcm 对每个质因子取**较大指数**。

因此这里 gcd 是 $2^1\times3^1=6$，lcm 是 $2^2\times3^2=36$。对任意一个质因子，“较小指数 + 较大指数”恰好等于原来两个指数之和，所以 `gcd × lcm` 与 `a × b` 的每个质因子指数都相同。

手写模板：

```cpp
// 与上一节 gcd_ll 放在一起使用。
// 前提：a、b 非负，且最小公倍数能用 long long 表示。
long long lcm_ll(long long a, long long b) {
    if (a == 0 || b == 0) return 0;
    return a / gcd_ll(a, b) * b;
}
```

这里有两个细节：

- **先处理 0**，避免在 `a == b == 0` 时除以 `gcd_ll(0, 0)`，也就是除以 0。
- **先除后乘**，避免 `a * b` 这个中间结果溢出。先除后乘只能减少中间溢出，最终答案仍须在类型范围内。

对于正整数，该模板求 lcm 的时间复杂度主要由 gcd 决定，也是 $O(\log \min(a,b))$，额外空间为 $O(1)$。

## 5. 常见用法

### 5.1 分数约分

例如，把 `12/18` 化为最简分数：

```cpp
long long numerator = 12;
long long denominator = 18;
long long g = std::gcd(numerator, denominator);

numerator /= g;
denominator /= g;

std::cout << numerator << '/' << denominator;  // 2/3
```

分子、分母同时除以同一个非零数，分数值不变；除去最大公约数后，剩下的分子、分母互质，不能再继续约分。这里假设分子、分母为正整数。

### 5.2 求多个数的 gcd / lcm

两数的函数可以逐个累计：

```cpp
long long g = std::gcd(std::gcd(12LL, 18LL), 30LL);  // 6
long long l = std::lcm(std::lcm(4LL, 6LL), 10LL);    // 60
```

对于一个非负整数数组 `a`，可以写成：

```cpp
long long g = 0;
for (long long x : a) {
    g = std::gcd(g, x);
}
```

初始化为 0，是因为 `gcd(0, x) = x`，第一个数可以自然加入计算。

如果数组全部是正整数，累计 lcm 可以从 1 开始，因为 `lcm(1, x) = x`；每一步的结果都必须能用所选类型表示。

### 5.3 两个常用特例

对正整数：

- 如果 `a` 能整除 `b`，那么 `gcd(a,b) = a`，`lcm(a,b) = b`。
- 如果 `a`、`b` 互质，那么 `gcd(a,b) = 1`，`lcm(a,b) = a*b`。

## 6. 洛谷例题一：P1888 三角函数

**原题链接**：[P1888 三角函数](https://www.luogu.com.cn/problem/P1888)。本节概括题意，完整题面以原题为准。

**练习重点**：把实际问题转化为分数，再用 gcd 约分。

### 6.1 题意与切入点

给出直角三角形的三条正整数边，输入顺序不固定。输出较小锐角的正弦值，结果用最简分数表示。三条边均不超过 $10^9$。

直角三角形中：

$$
\sin\theta=\frac{\text{这个角的对边}}{\text{斜边}}
$$

较小锐角对应较短的直角边，而斜边是最长边。因此，只需要取三数中的**最小值与最大值**，组成分数后约分。

### 6.2 自拟演示

输入三条边 `10 6 8`：

1. 最短边是 6，最长边是 10，分数为 `6/10`。
2. `gcd(6,10) = 2`。
3. 分子、分母都除以 2，输出 `3/5`。

### 6.3 正确性与复杂度

最短边是较小锐角的对边，最长边是斜边，所以构造的分数就是所求正弦值；同时除以最大公约数保持分数值不变，并得到最简形式。

令最短边为 $s$，最长边为 $t$，时间复杂度为 $O(\log\min(s,t))$，额外空间为 $O(1)$。

### 6.4 思路回顾与 C++17 代码

**读入三条边 → 找最短边和最长边 → 求 gcd → 同时除以 gcd → 按分数格式输出。**

```cpp
#include <algorithm>
#include <iostream>
#include <numeric>

int main() {
    long long a, b, c;
    std::cin >> a >> b >> c;

    long long shortest = std::min({a, b, c});
    long long longest = std::max({a, b, c});
    long long g = std::gcd(shortest, longest);

    std::cout << shortest / g << '/' << longest / g << '\n';
    return 0;
}
```

**代码流程**：`min/max` 找到分子和分母，`gcd` 找到要同时除去的公因子，最后输出整数、斜杠、整数。不要用浮点除法输出小数。

## 7. 洛谷例题二：P1029 最大公约数和最小公倍数问题

**原题链接**：[P1029 [NOIP 2001 普及组] 最大公约数和最小公倍数问题](https://www.luogu.com.cn/problem/P1029)。本节概括题意，完整题面以原题为准。

**练习重点**：利用 gcd 与 lcm 的乘积关系，把两个数的枚举缩减为因数配对。

### 7.1 题意与符号

给定两个正整数 $x_0,y_0$，统计满足下列条件的**有序正整数对** $(P,Q)$ 的数量：

$$
\gcd(P,Q)=x_0,\qquad\operatorname{lcm}(P,Q)=y_0
$$

原题数据范围为 $2\leq x_0,y_0\leq10^5$。这里“有序”表示 `(3,60)` 和 `(60,3)` 要分别计数。

### 7.2 先看一个具体例子

取 $x_0=3,y_0=60$。合法数对有：

```text
(3, 60)、(12, 15)、(15, 12)、(60, 3)
```

为了去掉每个数里必然含有的公因子 3，把两边都除以 3：

```text
(1, 20)、(4, 5)、(5, 4)、(20, 1)
```

你会发现：每一对的乘积都是 20，而且每一对都互质。下面把这个观察推广。

### 7.3 第一步：判断有没有可能存在答案

最大公约数一定整除最小公倍数：因为 $x_0$ 整除 $P$，而 $P$ 又整除 $y_0$，所以 $x_0$ 必须整除 $y_0$。

```cpp
if (y0 % x0 != 0) {
    std::cout << 0 << '\n';
    return 0;
}
```

### 7.4 第二步：除去共同因子

设：

$$
P=x_0u,\qquad Q=x_0v
$$

因为 $x_0$ 已经是最大公约数，所以剩下的 $u,v$ 必须互质：如果它们还共同含有大于 1 的因子 $d$，那么 $x_0d$ 就能同时整除 $P,Q$，与“最大公约数是 $x_0$”矛盾。

再利用乘积关系：

$$
PQ=x_0y_0
$$

代入并约去 $x_0^2$，得到：

$$
uv=\frac{y_0}{x_0}
$$

记 $n=y_0/x_0$，原问题就转化为：

> 找出多少组有序正整数对 `(u,v)`，满足 `u*v == n`，并且 `gcd(u,v) == 1`。

### 7.5 第三步：成对枚举因数

以 $n=20$ 为例，只枚举较小的那个因数：

| u | v = n/u | gcd(u,v) | 对答案的贡献 |
| --- | --- | --- | --- |
| 1 | 20 | 1 | 加 2：`(1,20)`、`(20,1)` |
| 2 | 10 | 2 | 加 0：不互质 |
| 4 | 5 | 1 | 加 2：`(4,5)`、`(5,4)` |

总数为 4。

为什么只枚举到平方根？对 `u*v=n`，至少有一个数不超过 $\sqrt n$，所以枚举较小因数不会漏掉任何一对。

- `u != v` 时，交换顺序能得到两个不同的有序数对，因此加 2。
- `u == v` 时，交换前后相同，只加 1。对互质要求来说，这种情况只会是 `u=v=1`，即 `x0=y0`。

### 7.6 正确性与复杂度

每个原问题的合法数对，除以 $x_0$ 后都对应一对乘积为 $n$ 的互质正整数。

反过来，若 `u*v=n` 且 `gcd(u,v)=1`，把它们同时乘上 $x_0$，得到的两个数最大公约数就是 $x_0$；再由乘积关系，其最小公倍数就是 $x_0uv=y_0$。所以这种转化既不遗漏合法数对，也不引入非法数对。

枚举较小因数覆盖了每一组因数配对，再按有序性计数，因此答案正确。

循环进行 $O(\sqrt n)$ 次，每次 gcd 最多需要 $O(\log n)$ 时间；总时间上界为 $O(\sqrt n\log n)$，额外空间为 $O(1)$。$n=1$ 时直接在一次循环中得到答案 1。

### 7.7 另一种可行方法与对比

也可以枚举 `P` 从 `x0` 到 `y0`，利用 `Q=x0*y0/P` 得到另一个数，再检查整除和 gcd。在本题数据范围内，这种方法也可行，粗略时间上界为 $O(y_0\log y_0)$；计算 `x0*y0` 时需要 `long long`。

| 方法 | 枚举内容 | 特点 |
| --- | --- | --- |
| 直接枚举 P | `x0...y0` 内的整数 | 思路直接，但候选较多 |
| 除去 gcd 后枚举因数对 | `1...sqrt(y0/x0)` 内的整数 | 范围更小，主解采用此法 |

### 7.8 思路回顾与 C++17 代码

**检查 `x0` 能否整除 `y0` → 计算 `n=y0/x0` → 枚举因数对 → 判断互质 → 按顺序是否不同累计答案。**

```cpp
#include <iostream>
#include <numeric>

int main() {
    long long x0, y0;
    std::cin >> x0 >> y0;

    if (y0 % x0 != 0) {
        std::cout << 0 << '\n';
        return 0;
    }

    long long n = y0 / x0;
    long long ans = 0;

    // u <= n / u 等价于 u*u <= n，并避免乘法溢出。
    for (long long u = 1; u <= n / u; ++u) {
        if (n % u != 0) continue;

        long long v = n / u;
        if (std::gcd(u, v) != 1) continue;

        ans += (u == v ? 1 : 2);
    }

    std::cout << ans << '\n';
    return 0;
}
```

**代码流程**：`n % u` 排除非因数，`v = n/u` 确定另一半，`gcd` 检查互质，最后用条件运算符区分加 1 和加 2。程序只需要计数，所以不必实际构造 `P=x0*u` 和 `Q=x0*v`。

自拟检查数据：

| 输入 | 应输出 | 检查点 |
| --- | --- | --- |
| `3 60` | `4` | 一般情况与有序计数 |
| `6 6` | `1` | 两个数相等时不能重复计数 |
| `4 6` | `0` | 最大公约数不能整除最小公倍数 |
| `2 8` | `2` | `(2,8)`、`(8,2)`，中间的 `(4,4)` 不合法 |

## 8. 易错点与练习建议

| 易错点 | 正确理解 |
| --- | --- |
| 把公约数当成只有一个数 | 公约数可能有多个；gcd 只返回最大的 |
| 把 lcm 写成 `a*b` | 只有互质时才等于乘积；一般要除以 gcd |
| 忘记 `<numeric>` 或使用过旧标准 | 标准函数需要 `<numeric>` 和 C++17 起的支持 |
| 认为接收变量是 long long 就不会溢出 | 调用前就要保证参数类型足够宽 |
| 手写 lcm 直接 `a*b/gcd(a,b)` | 优先 `a/gcd(a,b)*b`，并保证最终结果可表示 |
| 手写 lcm 不考虑两个参数都是 0 | 先判断是否有参数为 0，避免除以 0 |
| P1029 每个合法因数对都加 2 | 两数相等时只能加 1 |

建议按以下顺序练习：

1. 自己算出 12 和 18 的全部公约数，再算 gcd 和 lcm。
2. 不看模板，手推 `gcd(48,18)` 的每次状态变化。
3. 运行第 3 节的程序，用 `8 15`、`6 24`、`0 18` 检查结果。
4. 完成 P1888，练习 `std::gcd` 和约分。
5. 完成 P1029，重点解释“为什么除去最大公约数后必须互质”和“为什么有时加 2、有时加 1”。

前面三组输入的预期输出分别是 `1 120`、`6 24`、`18 0`。
