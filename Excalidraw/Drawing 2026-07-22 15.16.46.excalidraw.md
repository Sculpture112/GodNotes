fillDp()：从右往左计算后缀 LIS 的 dp ^title

核心不变量：endsArr[j] = 长度为 j+1 的递增子序列中，最大的开头值 ^subtitle

len = endsArr 有效长度 = 当前最长递增子序列长度 ^initText

find = bs(len, nums[i])
找 endsArr 中第一个 <= nums[i] 的位置 ^bsText

find == -1 ? ^Sa55ISS4

是 ^yesLabel

所有 endsArr 都 > x
x 能接在当前最长序列前面
endsArr[len] = x
len++
dp[i] = len ^yesText

否 ^noLabel

p = find
前 p 个层级的开头都 > x
x 能形成长度 p+1
endsArr[p] = x
dp[i] = p+1
len 不变 ^noText

i--，继续处理左边
循环结束后 return len ^MDfxRr9Q

为什么只保留“最大开头”？开头越大，越容易让左边更小的数接在前面。 ^whyText
