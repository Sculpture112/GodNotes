# Excalidraw Data

## Text Elements
范围内数字计数：从题意到按位统计公式 ^t

题意：统计 [a,b] 内 0~9 的出现次数 ^x1

区间转前缀：count(b,d) - count(a-1,d) ^x2

子问题：d 在 1~n 中出现几次？ ^x3

逐位枚举：right = 1, 10, 100, ... ^x4

按当前位拆分：left | cur | low ^x5

基础贡献：left × right（完整高位段） ^x6

cur>d 加 right；cur=d 加 low+1；否则不加 ^x7

d=0：排除前导零，所以 left-- ^x8

否则会把 7 当成 007，错误多算 0 ^x9

例：n=259，统计十位的 d=3：left=2，cur=5，right=10，low=9 ^x10

完整段：30~39、130~139，共 2×10；cur=5>3，再加 230~239 ^x11

十位上数码 3 的贡献 = 30 ^x12

所有位贡献相加 ^x13

输出 d=0~9；O(log n) ^x14
